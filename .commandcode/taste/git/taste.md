# Commit and PR preferences

- Use conventional commits with scope prefixes matching the subsystem, e.g. `refactor(cli):`, `refactor(i18n):`, `refactor(tui):`, `chore:`. Confidence: 0.85
- Ship substantial coherent batches, but each batch must leave the project compiling with applicable tests passing. Confidence: 0.8
- Never use broad formatting changes to obscure behavioral changes. Confidence: 0.9
